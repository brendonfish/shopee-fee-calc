# 蝦皮帳單試算 shopee-fee-calc

蝦皮的對帳單會列出每項費用扣了多少，但它不知道你的進貨成本、自己貼的運費和廣告費，也不會告訴你免運方案選得對不對。

這個工具幫你算三件事：

1. [這單扣掉成本，到底賺多少](#一這單到底賺多少)
2. [上架前，這個價格會不會虧](#二上架前這個價格會不會虧)
3. [方案一和方案二，該不該換](#三方案一和方案二該不該換)

這是一個 AI skill，裝進 Claude 或 Codex 之後，用講的就能算，不用自己記公式。

費率依蝦皮賣家中心 2026-09-08 的官方公告。蝦皮規則常改，用之前請到賣家中心核對。

## 一、這單到底賺多少

對帳單上的「撥款」只是蝦皮扣完費用給你的錢，還沒扣進貨成本、你貼的運費和廣告費。

> 我在蝦皮賣一個 300 元的東西，成本 150 元，不知道自己在哪個方案，這單賺多少？

```
平台扣款：成交手續費 17、免運專案（方案二）60、金流服務費 8、發票服務費 2.5，合計 87.5 元
撥款（實拿）：212.5 元
淨利：62.5 元（毛利率 20.8%）
方案比較：方案一 18 元 / 方案二 60 元 → 這單用方案一可以少付 42 元
```

## 二、上架前，這個價格會不會虧

一次給幾個候選價格，比較每個價格扣完費用和成本還剩多少。組合包、湊單門檻也可以這樣算。

> 這個商品進價 120 元，我在方案二，想賣 199、249 或 299，各賺多少？

```
售價 199：平台扣 78.5 元，淨利 0.5 元（毛利率 0.3%）
售價 249：平台扣 82.5 元，淨利 46.5 元（毛利率 18.7%）
售價 299：平台扣 85.5 元，淨利 93.5 元（毛利率 31.3%）
```

## 三、方案一和方案二，該不該換

免運專案是整個賣場一起選的，要看所有訂單加起來，不能只看一單。很多賣家是被系統放進方案二的，不是自己選的。

> 這是我上個月的訂單，幫我看該不該換方案。（附上訂單 CSV）

```
整批 6 筆：商品金額 4,380 元，平台扣 763.5 元，撥款 3,616.5 元，淨利 1,576.5 元，虧錢 0 筆
訂單金額分布：99 元以下 1 筆、100–999 元 3 筆、1,000 元以上 2 筆
免運專案：全部用方案一共 263 元，全部用方案二共 303 元（目前方案二，付 303 元）
方案建議：這批訂單用方案一可以少付 40 元
```

大致的規則：

| 訂單金額 | 比較便宜的方案 |
| --- | --- |
| 99 元以下 | 兩個一樣，都收 6% |
| 100–999 元 | 方案一 |
| 1,000 元以上 | 方案二 |

拿最近一個月的訂單來算最準。方案 30 天內可以換一次。

## 安裝

### Claude 網頁版或 App

需要 Pro、Max、Team 或 Enterprise 方案，並先開啟「程式碼執行與檔案建立」。

1. 到 [Releases](../../releases) 下載最新版的 `shopee-fee-calc.zip`。
2. 進入 **設定 → 功能（Capabilities）**，找到 Skills 區塊。
3. 點 **上傳技能（Upload skill）**，選剛下載的 zip，上傳後把它打開。

### Codex

跟 Codex 說：

```
用 $skill-installer 從 brendonfish/shopee-fee-calc 安裝 skills/shopee-fee-calc
```

或手動：把 `skills/shopee-fee-calc` 資料夾放到 `~/.agents/skills/`，沒出現就重開 Codex。提示裡寫 `$shopee-fee-calc` 可以指定用它。

### Claude Code

把 `skills/shopee-fee-calc` 資料夾放到 `~/.claude/skills/`（所有專案都能用），或專案裡的 `.claude/skills/`。

> Windows 電腦如果跑不動，通常是 `python3` 指令不存在，跟 AI 說「改用 python 或 py -3 執行」就好。

## 準備訂單資料

算一單，直接講數字就好。算一批（用途三），把訂單從 Google 試算表或 Excel 下載成 CSV，第一列是標題，可用：

售價、數量、成本、買家運費、賣家運費、賣家折扣、成交手續費率、方案、檔期、商城、預購、蝦幣回饋、廣告費、其他成本、開發票

只有「售價」必填。範例：[`examples/sample-orders.csv`](examples/sample-orders.csv)。

算完會回傳一份多了「試算_撥款」「試算_淨利」「試算_毛利率」等欄位的 CSV，可以再匯回試算表。

- 原本的欄位不會被蓋掉，空白列會保留，貼回原表不會錯位。
- 金額有千分位、NT$、百分比、全形數字、Big5 編碼都讀得懂。
- 格式錯的列會標「錯誤」並寫原因，其他列照算。
- 欄位名稱對不上的（例如只寫「運費」）不會被使用，結果裡會列出來。

## 會算的費用

| 項目 | 怎麼算 |
| --- | --- |
| 成交手續費 | 售出金額（扣賣家折扣、不含運費）× 分類費率；一般賣家單件、單筆訂單以 35,000 元為上限 |
| 促銷檔期加收 | 一般賣家 +2%、商城 +3%；有參加蝦幣回饋就不加收 |
| 免運專案 | 方案一：商品金額 × 6%，不含運費。方案二：訂單 100 元以上每單 60 元，99 元以下收 6%。沒報名會被平台放進方案二 |
| 金流與系統處理費 | （商品金額＋運費）× 2.5%，照蝦皮券、蝦幣折抵前的金額算 |
| 預購訂單服務費 | 備貨 2 個工作日以上，3% |
| 蝦幣回饋 | 1.5% 或 3%；同時參加免運專案和 10% 蝦幣回饋，3% 減為 2.5% |
| 發票服務費 | 用蝦皮代開發票，每張 2.5 元 |

每項各自四捨五入到元再相加。完整規則、官方範例和程式的假設，見 [`fee-rules.md`](skills/shopee-fee-calc/references/fee-rules.md)。

## 限制

- 成交手續費每個分類不同，要填自己的（賣家中心有分類費率表）。沒填會先用 5.5% 假設。
- 商城的成交手續費上限、蝦幣回饋費的計算基礎，官方沒寫清楚，程式的假設寫在 `fee-rules.md`。
- 每月第一筆訂單免收免運專案費用，程式沒算。
- 物流隱碼費、環保無包裝交寄等個別服務費、信用卡分期的金流費，沒有算進去。
- 這是給老闆看的管理帳，不是報稅用的帳。

## 改費率

所有費率都在 [`fees.json`](skills/shopee-fee-calc/references/fees.json)。蝦皮改規則時只改這個檔的數字和 `fees_as_of` 日期，程式不用動。改完跑一次測試：

```
python3 tests/test_official_examples.py
```

測試用的是蝦皮官方公告裡的範例，全部通過才發新版。
